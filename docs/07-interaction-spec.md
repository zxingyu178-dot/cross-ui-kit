# 07 · 交互规范（四态、反馈、手势、动效）

本规范定义三栈统一的交互行为标准；`packages/interaction` 提供可复用实现（四态容器、反馈 hooks、手势封装），页面与组件必须遵循。

## 1. 页面/数据四态（强制）

| 状态 | 触发 | 表现标准 |
|---|---|---|
| loading | 首次加载/刷新 | 300ms 内不显示指示器（防闪烁）；超 300ms 显示**骨架屏**（布局与真实内容一致）；超 10s 提示"加载较慢"并给取消入口 |
| empty | 请求成功但无数据 | Empty：插画/图标 + 标题 + 说明 + 主行动按钮（去创建/去搜索/重新加载）；区分"真空"与"筛选无结果"（后者给"清空筛选"） |
| error | 请求失败/异常 | ErrorState：错误图标 + 友好说明（不暴露技术堆栈）+ 重试按钮；区分 403（无权限引导）、404、5xx（重试）、断网（检查网络） |
| normal | 正常 | 含空值占位（`--`）、超长文本省略策略、极值（0/超大数/负数）、长列表虚拟滚动 |

实现：统一用 core 的 `useRequest/useTable` 返回的 `loading/empty/error/data`，配合 interaction 包的 `<StateContainer>`（三栈各一份同名封装），**禁止每页各写一套判断**。

## 2. 操作反馈

- **即时操作**（开关、选择、收藏）：乐观更新 + 轻反馈（Toast/微动效）；失败回滚并提示；
- **提交类操作**（保存、提交、支付）：按钮进入 loading 且禁用（防重复提交，组件内置）→ 成功 Toast 并关闭/跳转 → 失败内联错误 + 恢复可点；
- **危险操作**（删除、清空、解绑）：必须二次确认（web Popconfirm/Dialog，mini/native ActionSheet/Dialog），按钮标 danger，说明后果；
- **耗时任务**（上传/导出/下载）：进度可见（Progress/系统通知），可取消，完成后通知；
- Toast 规则：成功 1.5~2s 自动消失；错误需用户可读原因；同一时刻同类 Toast 只保留一条。

## 3. 导航与路由

- 大端：侧边栏 + 面包屑 + Tabs；详情页支持浏览器前进后退；列表→详情保留列表滚动位置与筛选条件（core 提供缓存约定）；
- 小端：NavBar 固定返回（手势返回 iOS 边缘滑动、Android 物理返回键行为一致）；底部 Tabbar 切换不刷新已加载页；跳转传参走路由参数 + 类型化路由；
- 原生：Expo Router，栈导航与 Tab 导航与小端保持一致的信息架构；
- 统一守卫：未登录跳登录（带 redirect 回跳参数）、无权限显示 403 页；由 core 的权限层 + PermissionGate 组件实现。

## 4. 手势与触控（mini/native）

| 手势 | 行为标准 |
|---|---|
| 点击 | 最小热区 44×44px（`size-touch-min`），禁用态视觉降低且不响应 |
| 下拉刷新 | 列表页标配，刷新中显示标准刷新控件，失败 Toast 提示 |
| 触底加载 | 距底 200px 预加载；分页 loading 在底部；无更多显示"没有更多了" |
| 滑动操作 | 列表项左滑出现操作按钮（删除/置顶），最多 2 个，危险操作仍需确认 |
| 长按 | 触发上下文操作（多选/菜单），与 web 右键菜单信息架构一致 |
| 双指缩放 | 图片预览内置，页面布局禁止横向滚动（除明确横滑区域） |
| 返回手势 | 全局可用，表单页有未保存内容时拦截并确认 |

## 5. 表单交互

- 校验时机：失焦校验（非输入中即报错）；提交时全量校验并滚动定位到第一个错误；
- 错误展示：控件下方错误文案 + 错误态描边（`color-danger-default`），同时 aria 关联；
- 必填标记：label 前红色 `*`；提交按钮在必填未填时的策略由页面定（置灰 or 点击提示，二选一全库统一为"可点击后提示"，避免置灰导致用户找不到原因）；
- 输入约束：数字/手机号/金额用专用键盘类型；金额禁止输入多个小数点；
- 防丢失：长表单离开页面拦截确认；草稿自动保存（core 提供 useFormDraft）。

## 6. 动效

- 时长只用 token：fast 150ms（悬停/按压）、base 250ms（弹层/展开）、slow 400ms（页面转场/大元素）；
- 缓动：standard（进出）、decelerate（进入）、accelerate（退出）；
- 弹层：Dialog 居中缩放+淡入，Drawer/Sheet 滑入滑出，Dropdown 淡入+轻微位移；
- 尊重系统"减少动态效果"（web `prefers-reduced-motion`，native AccessibilityInfo），开启后仅保留必要淡入；
- 禁止纯装饰性大幅动画影响操作效率；loading 动画不得遮挡操作内容。

## 7. 响应式与布局断点（web）

- 断点 token：sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536；
- 大端内容区最大宽度 1440，栅格 24 列；小端 750rpx 设计基准（Taro 样式插件处理）；
- 自适应策略：优先弹性布局与栅格；表格在窄屏降级为卡片列表（DataTable 内置响应式模式）；导航在窄屏折叠为抽屉。

## 8. 暗色模式与主题

- 组件禁止写死颜色，全部走语义 token，暗色由 token 映射自动切换；
- 三端都提供亮/暗/跟随系统三选项，主题状态在 core 管理，切换无白屏闪烁（web 在根 class，mini 根节点 class，native Tamagui theme）；
- 图片/插画需提供暗色版本或加容器处理。

## 9. 国际化与无障碍交互

- 文案不拼接（用参数化 i18n）；日期/数字按地区格式化；
- 焦点可见（web focus ring 用 `color-border-focus`，不可移除）；
- 对比度满足 WCAG AA；小端读屏标签齐全（见 05 文档 §7）；
- 不仅依赖颜色表达状态（成功/失败同时有图标或文案）。

## 10. 断网与异常

- 请求层（core）统一处理超时（默认 15s）、重试（GET 幂等自动重试 2 次，指数退避）、断网检测；
- 断网时全局横幅提示，操作按钮禁用或排队；恢复后自动刷新当前页；
- 白屏/崩溃兜底：web ErrorBoundary 显示错误页（提供"刷新/返回首页"）；小程序 onError 上报 + 友好页；native ErrorBoundary 兜底屏。

## 11. 交互验收清单（评审逐项过）

- [ ] 四态齐全且走 StateContainer/useRequest 标准实现；
- [ ] 提交有 loading 防重、危险操作有确认、操作结果有反馈；
- [ ] 手势/热区/触底加载/下拉刷新符合 §4；
- [ ] 表单校验时机、错误定位、草稿策略符合 §5；
- [ ] 动效只使用 motion token 且尊重减少动效设置；
- [ ] 暗色、i18n、焦点、对比度、断网兜底验证通过。
